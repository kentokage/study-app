# Number Crunchers — Multiplication Practice

A small static app that generates multiplication problems for practice.

How to use
- Open `index.html` in a browser.
- Choose difficulty, then answer the multiplication problems.
- Score increases by +10 for correct answers, -5 for incorrect answers (score floor 0).
